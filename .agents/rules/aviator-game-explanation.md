# Aviator

Aviator is a popular "crash" style wagering game frequently targeted for automation due to its linear multiplier progression and data-driven nature.
Operational Rules

The game operates on a Provably Fair RNG (Random Number Generator) algorithm. The core mechanics are as follows:

    The Multiplier: A digital aircraft takes off with a multiplier starting at 1.00x. 

    The Ascent: As the plane flies, the multiplier increases. This is a continuous numerical progression. 

    The Objective: The user must trigger a "Cash Out" command before the aircraft "flies away" (the crash point). 

    Win Condition: If the user cashes out before the crash, the payout is calculated as Stake×Multipliercurrent​.

    Loss Condition: If the aircraft disappears before the user cashes out, the entire stake is forfeited.

The game displays three different colors to represent a range of scores:

Blue | x1.00 - x1.99
Purple | x2.00 - x9.99
Pink | x10.00 - ...
