# Robotcasino & Docker

Docker is a software that creates/runs containers based on an Docker Image which specifies the step-by-step to run a program/software/service.

## Why is Docker important for Robotcasino?

Docker will used to run all game sessions requested by the users, which makes it the cornerstone of the project itself. This implementation transforms our architecture to a central one, because the VPS will be the responsible to share its resources (memory, processor, etc) and to maintain all data secured and no one can access it without authorization.
