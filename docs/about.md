# Robotcasino

Welcome to the official RobotCasino documentation. In this page you will learn about what this project is and our main goals.

## What is Robotcasino?

Robotcasino is a scraper that plays popular casino games following a strategy automatically
24/7. We bet to automate Crash games such as Aviator (Spribe), Spaceman (Pragmatic Play), 
Crash (Stake), etc.

Clients will be able to start game sessions using a Telegram bot, see status, statistics and take screenshot of the running session.

## Our goals

- To be the first service in the world of gambling offering this kind of scraping services.
- To be the safest service in the world of gambling, because this service violates the terms and conditions of casinos.
- To have the largest game repository from different casinos.
